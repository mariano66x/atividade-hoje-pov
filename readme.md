Repositório criado para praticar comandos básicos de Git e GitHub.

Inclui: inicialização (`git init`), staging (`git add`), commits (`git commit`), renomeação de branch (`git branch -M main`), conexão remota (`git remote add`), push (`git push`), branches (`git checkout -b`, `git merge`) e correção de remoto (`git remote set-url`).
